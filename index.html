01 · About

About me

I am a data engineer from Lahore, Pakistan. I graduated in Data Science from PUCIT, University of the Punjab, in 2026, where I also taught database systems and data warehousing as a teaching assistant.

I have worked as a freelance data engineer since 2023, building database driven solutions for clients remotely. My work centers on correctness: pipelines that return the right answer, not just any answer.

Most of my open source work is correctness fixes in the data stack: schema merges that dropped nullability, timestamp statistics that silently lost bounds, and predicate checks that leaked the wrong rows. The bugs I care about most are the ones that do not crash. They quietly return wrong results.

Focus: Python, SQL, Apache Spark, Databricks, Delta Lake, dbt, CDC, Medallion Architecture.

05 · How I Work

How I work

A simple process, from understanding the data to proving the result is correct.

01

Understand the data

Read the source, check what correct looks like, and find where the pipeline can silently go wrong.

02

Build the pipeline

Incremental ingestion with CDC and Delta Lake MERGE, dbt models for transformation, and tests for data quality.

03

Prove it is correct

Reproduce the bug first, validate against the source, and ship with tests so the wrong answer cannot come back.

04

Share what I learned

Write it up on Medium, open source the fix, and keep the notes so the next person does not hit the same bug.
